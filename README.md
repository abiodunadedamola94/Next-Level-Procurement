# Next Level Procurement: homepage redesign concept

A design concept for nextlevelprocurements.com, prepared by MoCreative Concept. It is not the live site: production still deploys from `main`.

- All copy is taken from the current site (`main`): services, regions, values and the WhatsApp line. Nothing new is claimed.
- The order tracker, supplier scorecard and platform screen are labelled as samples or design concepts.
- Static HTML, CSS and JS. Edit `index.src.html`, then run `node build.mjs` to inline the icons into `index.html`.
- `noindex` (meta tag and header), so it stays out of search results.
